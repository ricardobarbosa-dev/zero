Do Zero ao Código de Produção

Programação Orientada a Objetos Sem Segredos.

Esqueça explicações abstratas. Aqui está o mapeamento completo de como a POO estrutura sistemas reais, dividido por níveis de complexidade.

Nível 01 — Iniciante

Classes, Atributos e Construtor (__init__)

Quando usar: Sempre que você precisar agrupar dados e comportamentos relacionados para não deixar variáveis soltas no seu script.
Exemplo real: Gerenciar os dados de uma conta de usuário em um sistema.

usuario.py
class Usuario:
    def __init__(self, username, email):
        self.username = username  # Atributo
        self.email = email        # Atributo
        self.esta_ativo = True   # Atributo padrão

    def desativar(self):        # Método (Ação)
        self.esta_ativo = False

# Usando o molde para criar instâncias reais
user_1 = Usuario("rick_dev", "rick@email.com")
user_1.desativar()
print(f"Status do {user_1.username}: {user_1.esta_ativo}")
$ python usuario.py
Status do rick_dev: False
Nível 02 — Intermediário

Herança e Reaproveitamento Eficiente

Quando usar: Quando você tem múltiplos tipos de entidades que compartilham a mesma base estrutural, mas possuem regras de negócio ou permissões adicionais.
Exemplo real: Separar usuários comuns de Administradores em um portal de gerenciamento.

usuarios_roles.py
class Usuario: # Classe Base (Pai)
    def __init__(self, username):
        self.username = username

    def obter_dashboard(self):
        return "Painel Visual Padrão"

class Admin(Usuario): # Classe Especializada (Filha)
    def __init__(self, username, nivel_acesso):
        super().__init__(username) # Herda o construtor do Pai
        self.nivel_acesso = nivel_acesso

    def deletar_banco_de_dados(self): # Exclusivo de Admin
        return "Executando DROP DATABASE..."

adm = Admin("rick_admin", 5)
print(adm.obter_dashboard())
print(adm.deletar_banco_de_dados())
$ python usuarios_roles.py
Painel Visual Padrão
Executando DROP DATABASE...
Nível 03 — Avançado

Polimorfismo Aplicado à Arquitetura

Quando usar: Quando o núcleo do seu sistema precisa interagir com ferramentas externas (como gateways de pagamento ou enviadores de e-mail), mas a forma exata de como cada um executa a tarefa não importa para o fluxo principal.
Exemplo real: Processador de pagamentos aceitando PIX e Cartão de Crédito de forma dinâmica.

checkout.py
class MetodoPagamento:
    def processar(self, valor):
        raise NotImplementedError("Subclasses devem implementar este método")

class PagamentoPix(MetodoPagamento):
    def processar(self, valor):
        return f"Gerando QR Code para pagamento de R$ {valor:.2f}"

class PagamentoCartao(MetodoPagamento):
    def processar(self, valor):
        return f"Contatando operadora do cartão para transação de R$ {valor:.2f}"

# Função de checkout do seu e-commerce não se importa com a forma de pagamento
def finalizar_venda(forma_pagamento, total):
    print(forma_pagamento.processar(total))

finalizar_venda(PagamentoPix(), 150.00)
finalizar_venda(PagamentoCartao(), 450.50)
$ python checkout.py
Gerando QR Code para pagamento de R$ 150.00
Contatando operadora do cartão para transação de R$ 450.50
Nível 04 — Expert

Encapsulamento e Getters/Setters com Getters reais (`@property`)

Quando usar: Para evitar fraudes de estado em variáveis sensíveis. Se você deixar o saldo de uma carteira ou o preço de um item expostos diretamente, qualquer parte externa do código pode sobrescrever o dado sem nenhuma validação prévia.

carteira.py
class CarteiraDigital:
    def __init__(self):
        self.__saldo = 0.0  # Atributo Privado (Dois underscores)

    @property  # Transforma a função em um Atributo de leitura limpo
    def saldo(self):
        return self.__saldo

    @saldo.setter  # Controla e valida qualquer tentativa de alteração
    def saldo(self, novo_valor):
        if novo_valor < 0:
            raise ValueError("Saldo não pode ser negativo!")
        self.__saldo = novo_valor

minha_carteira = CarteiraDigital()
minha_carteira.saldo = 250.00  # Altera de forma segura
print(f"Saldo Atual: R$ {minha_carteira.saldo}")

minha_carteira.saldo = -50  # Dispara exceção de erro
$ python carteira.py
Saldo Atual: R$ 250.00
ValueError: Saldo não pode ser negativo!

O Grande Segredo da Produção: Composição

Muitos professores falham em explicar que, no mercado real, nós evitamos abusar de Herança profunda (uma classe herdando de outra que herda de outra). Em vez disso, usamos a **Composição** (injetar objetos dentro de outros objetos).

class BancoDeDados: # Objeto A
    def executar(self, query): return "Resultados"

class RankingService: # Objeto B
    def __init__(self, banco_dados):
        self.db = banco_dados # COMPOSIÇÃO: B depende de A

Isso torna o código desacoplado e infinitamente mais fácil de aplicar testes automatizados.
